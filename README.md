# Doctor Who — Ma Première Aventure

Collection de livres-jeux interactifs courts, pensée pour les jeunes enfants et inspirée du principe des livres à choix.

## Principe

- Choisir un personnage au début de l'aventure.
- Garder une **roue personnage** toujours visible.
- Trouver, perdre ou échanger un objet via une **roue objet**.
- Lire des scènes très courtes.
- Faire **3 choix visuels** à chaque étape importante.
- Découvrir plusieurs chemins et **3 fins principales**.
- Rejouer avec un autre personnage pour voir des variantes.

## Collection prévue

1. **Le Docteur a disparu !** — boucle temporelle, Londres, vaisseau Dalek, TARDIS.
2. **Les Anges du Musée** — musée nocturne et Anges Pleureurs.
3. **Le Dinosaure de Londres** — aventure légère autour d'un dinosaure perdu dans le temps.
4. **Panique dans le TARDIS** — exploration de salles impossibles du TARDIS.
5. **Le Dernier Dalek** — aventure spatiale plus épique.

Chaque histoire sera écrite et testée séparément pour conserver une bonne cohérence.

## Structure

- `index.html` : application.
- `styles.css` : interface responsive.
- `app.js` : moteur générique.
- `books/book-01.js` : Livre 1, entièrement indépendant.
- Les livres suivants seront ajoutés dans `books/`.

## Lancer

Ouvrir `index.html` dans un navigateur ou activer GitHub Pages sur la branche `main`.

Projet fan-made non officiel. Doctor Who et les éléments associés appartiennent à leurs ayants droit.
